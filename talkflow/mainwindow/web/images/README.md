# Banner images

The Dictation page's hero banner rotates through tips about different features (like Wispr's "Transform works anywhere" promo card). Each tip can have its own background image — drop a file at the exact path below and it's picked up automatically, no code changes needed. Until a file exists for a given tip, that tip falls back to a CSS gradient with floating app icons.

Recommended size ~1400x400px (displayed at 168px tall, full width, object-fit: cover — landscape works best). Dark/moody backgrounds work well since white text is overlaid on the left side.

- `banner-dictation.png` — core dictation tip
- `banner-transforms.png` — Transforms tip
- `banner-command_mode.png` — Command Mode tip
- `banner-snippets.png` — Snippets tip
- `banner-dictionary.png` — Dictionary tip
- `banner-notetaker.png` — Notetaker tip
